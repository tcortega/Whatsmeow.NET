# Whatsmeow.Protocol

The generated gRPC and protobuf code of `whatsmeow.v1`, the contract between [`Whatsmeow.Client`](https://www.nuget.org/packages/Whatsmeow.Client) and its `whatsmeow-net` sidecar.
`Whatsmeow.Client` depends on it; you never reference it yourself.
It is for the library's own use, with no stability promise.
