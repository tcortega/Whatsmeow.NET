# Guidelines

How to write code in this repo.
[ARCHITECTURE.md](../ARCHITECTURE.md) says what we build; these say how.
Read only the file that matches the work.

* [csharp.md](csharp.md): any C# under `dotnet/`.
* [options.md](options.md): options and configuration in `Whatsmeow.Client` or `Whatsmeow.Extensions.Hosting`.
* [tests.md](tests.md): before writing or touching a test, .NET or Go.
* [go.md](go.md): any Go under `sidecar/`.
* [proto.md](proto.md): any `.proto` under `proto/whatsmeow/v1/`.
